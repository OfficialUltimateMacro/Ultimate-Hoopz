# Ultimate wordmark

`ultimate-wordmark.png` is the generated, transparent RGBA asset used for both the menu header and floating icon. Dimensions: 1774 × 887. It was created with the built-in imagegen tool using the user's screenshot as a style reference, then copied into this project without changing its alpha channel.

Final generation prompt:

> Create a transparent-background game UI wordmark asset. The attached screenshot is a STYLE REFERENCE ONLY: inspect the small pink 'blessed' wordmark inside the dark menu header and floating black button. Generate ONLY a standalone replacement wordmark reading exactly 'Ultimate' (U-l-t-i-m-a-t-e), no other text. Match its compact expressive hand-drawn gothic/graffiti lettering: candy pink fill, pale pink/silver outer outline, dark plum inset shadows, glossy dimensional highlights, pointed flourishes extending from the first and last letters. Horizontal centered wordmark, generous transparent padding so strokes are not clipped, clear silhouette readable at about 110 pixels wide. No black tile, no UI, no screenshot, no background, no extra symbols or watermarks. This is the Ultimate brand logo to replace both Blessed logos.
